📡 Nextel Local

Chamadas privadas por Wi-Fi: chame, aguarde o aceite e segure para falar.

Início Criar acesso APK adm_cadastro

O que você precisa

  1. Mantenha o computador servidor e os celulares no mesmo Wi-Fi.
  2. No menu, toque em Criar acesso e crie seu ID e sua senha.
  3. No app, entre com ID e senha. O servidor será encontrado automaticamente, sem digitar IP.
  4. Escolha uma pessoa e toque em Chamar. Os dois celulares tocarão dois bipes; a pessoa chamada precisará aceitar.
  5. Após o aceite, segure o botão para falar e solte para parar. Só os participantes da chamada ouvem.

Deixe o aplicativo aberto para receber convites. O servidor e os aparelhos precisam continuar ligados. Este protótipo usa Wi-Fi local; não acessa rádio SMR, iDEN ou rede de operadora.
