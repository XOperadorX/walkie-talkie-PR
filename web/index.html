📡 Nextel Local

Rádio em grupo: pressione para falar e solte para encerrar.

Criar acesso

O ID será criado após o cadastro. Use uma senha com pelo menos 8 caracteres.

Aplicativo Android · versão 1.1

Baixar APK

O botão ficará disponível quando o APK de depuração for compilado e salvo na pasta do projeto.

O que você precisa

1. Deixe o computador e os celulares conectados ao mesmo roteador Wi-Fi.
2. Abra esta página no computador e faça o cadastro.
3. No app, informe o IP exibido no terminal do servidor, seu ID e sua senha.
4. Permita o uso do microfone. Toque e segure para falar; solte para terminar. Todos na sala geral ouvem.

O servidor e os aparelhos precisam continuar ligados. A comunicação de áudio funciona na rede local; não é necessário internet externa. Este protótipo não acessa rádio SMR nem a rede iDEN da Nextel.
